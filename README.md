# WebEngineering2
Abgabe für die Vorlesung Webengineering 2: Es wird eine Progressive-Web-Applikation entwickelt die auf einer Karte die eigene Position (oder einen ausgewählten Standort) und Informationen zum entsprechenden Ort anzeigt. Außerdem wird eine Fahrradroute von der aktuellen Position zu einem ausgewählten Ort dargestellt.
